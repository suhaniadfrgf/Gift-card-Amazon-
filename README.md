# ShopSpark / PhotoWave Demo Website

A responsive, fictional educational demo website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder (not the ZIP itself).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

## Demo flow
- `index.html`: landing page
- `login.html`: fictional PhotoWave login screen
- `verify.html`: simulated verification
- `success.html`: demo completion screen
- `info.html`: educational disclaimer

Sample values: `demo_user` / `demo123`

The form validates these values in the browser only. It does not send or store credentials. Do not modify this demo to collect real third-party passwords or impersonate a real service.
